# Luminous Beauty Studio

Create a beauty cosmetic website. Choose an appropriate logo that will appear inside the website and that will appear when you load the page on a website. Then make it more detailed with the Home tab and other four tabs. For example, About Us, Services, another tab of services, and another tab of something else. Make it professional and include sample works that have been undertaken by that beauty cosmetic website. Then give it an appropriate name that can be used in the United States.
